# Calle Loira boundary openings

The Juan Gris sequence looks west with the Loira wall on the right. The
stations use the source order, estimated distances from the phone pins and
the existing wall trace in map metres. There are no solved ground cameras.
The existing Loira wall alignment and LiDAR ground datum are retained.
