# Upload photos here

Drop original photos of Villacana into this folder.

- Upload the **original files**, not screenshots. Originals record where each photo
  was taken and which way the camera pointed, which is how they get pinned to the map.
- On an iPhone, when choosing photos tap **Options** and leave **Location** on.
- Any file names are fine. They get sorted, named and moved into `photos/` after
  they have been pinned.
